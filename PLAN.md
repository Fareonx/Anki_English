# План: приложение-клон Anki для подготовки к IELTS

## 1. Цель

- Брат каждый день учит английские слова для IELTS по методу интервального повторения — **точно так же, как в Anki**.
- Старший брат (админ) **удалённо**:
  - добавляет слова наборами (категориями), например «50 слов»;
  - каждый день видит прогресс: сколько выучено, сколько осталось, какие слова даются тяжело.
- Брат тоже может сам добавлять слова, но только в категории.

## 2. Как работает Anki (это мы воспроизводим)

### 2.1. Основные понятия

| Понятие Anki | Что это у нас |
|---|---|
| **Note (заметка)** | Одно слово со всеми полями: слово, перевод, транскрипция, определение, пример, синонимы |
| **Card (карточка)** | То, что показывается на экране. Из одного слова получаются 2 карточки: EN→перевод (узнавание) и перевод→EN (вспоминание) |
| **Deck (колода)** | **Категория.** Колоды вкладываются друг в друга: `IELTS::День 01`, `IELTS::День 02`… |
| **Revlog (журнал ответов)** | Запись о каждом ответе. Из него строится вся статистика для админа |

### 2.2. Состояния карточки

```
 New ──► Learning ──► Review ──(забыл)──► Relearning ──► Review
(новая)  (изучение)  (повторение)        (переучивание)
```

### 2.3. Четыре кнопки ответа

**Again** (не вспомнил) · **Hard** (с трудом) · **Good** (вспомнил) · **Easy** (легко)

### 2.4. Алгоритм (классический Anki SM-2, стандартные настройки Anki)

**Новые и изучаемые карточки.** Шаги изучения `1m 10m`.

| Кнопка | Что происходит |
|---|---|
| Again | Карточка возвращается на первый шаг и появится через 1 минуту |
| Hard | Шаг повторяется. На первом шаге интервал = среднее первых двух шагов (~6 мин) |
| Good | Переход на следующий шаг. После последнего шага карточка **выпускается**: следующий показ через **1 день** (graduating interval) |
| Easy | Карточка сразу выпускается, следующий показ через **4 дня** (easy interval) |

**Карточки на повторении.** У каждой карточки есть «лёгкость» (ease): стартует с 250%, минимум 130%.

| Кнопка | Новый интервал | Лёгкость |
|---|---|---|
| Again | Карточка забыта (lapse): переучивание через 10 минут, потом интервал = 1 день | −20% |
| Hard | интервал × 1.2 | −15% |
| Good | (интервал + половина дней опоздания) × ease | не меняется |
| Easy | (интервал + дни опоздания) × ease × 1.3 (easy bonus) | +15% |

Дополнительные правила:
- К интервалам добавляется небольшой случайный разброс (fuzz), чтобы карточки не скапливались в один день.
- Новый интервал всегда хотя бы на 1 день больше предыдущего. Максимум — 100 лет.
- **Leech («пиявка»).** Слово, забытое 8 раз, помечается как проблемное. Админ видит такие слова в отчёте.

**Лимиты на день** настраиваются для каждой колоды:
- новых карточек: 20 по умолчанию, у нас будет 50;
- повторений: 200.

**Новый день** начинается в 04:00, а не в полночь.

**Порядок показа в сессии:**
1. Сначала изучаемые карточки, у которых подошло время.
2. Потом повторения старых слов вперемешку с новыми.
3. Две карточки одного слова не показываются в один день (bury siblings).

### 2.5. Как это решает сценарий «50 слов в день»

- Админ добавляет категорию `IELTS::День 05` из 50 слов. Лимит новых — 50 в день.
- Брат выучил 40, осталось 10. Эти 10 просто остаются «новыми» и придут завтра. Ничего не теряется.
- Завтра появляется `День 06`. Дальше два варианта:
  - Брат нажимает на родительскую колоду `IELTS`. Тогда остатки `Дня 05`, новые слова `Дня 06` и **повторения всех старых слов** идут вперемешку. Это и есть «соединить».
  - Брат нажимает только на `День 06`. Тогда учит только его.
- Старые слова сами всплывают в нужные дни (через 1, 3, 7, 18… дней). Это и есть главная сила Anki.
- **Custom Study**, как в Anki: «добавить ещё N новых сегодня», «повторить забытые сегодня», «зубрёжка категории без влияния на расписание».

### 2.6. FSRS — современный алгоритм Anki (на будущее)

С версии 23.10 в Anki есть альтернативный алгоритм FSRS. Пользователь задаёт желаемую долю запоминания (по умолчанию 90%), а алгоритм сам подбирает интервалы по истории ответов. При той же запоминаемости повторений получается меньше.

Предлагаю так: начать с классического SM-2, а позже добавить FSRS переключателем в настройках. Для FSRS есть готовая библиотека `ts-fsrs`. Журнал ответов будем хранить в формате, совместимом с этим переходом.

## 3. Функции

### Для брата (ученик)
- Список категорий со счётчиками, как в Anki: **New / Learn / Due** (синий / красный / зелёный).
- Экран учёбы:
  - лицевая сторона карточки;
  - кнопка «Показать ответ»;
  - 4 кнопки, и на каждой подписан следующий интервал («<1м», «10м», «1д», «4д»);
  - горячие клавиши, как в Anki: пробел и 1–4.
- Озвучка слова: британское произношение через встроенный в браузер синтез речи, бесплатно.
- Добавление слов. Обязательно выбрать или создать категорию.
- Настройки колоды: лимит новых в день, порядок показа.
- Личная статистика и серия дней подряд (streak).

### Для админа (ты)
- **Добавление слов удалённо:**
  - по одному;
  - **пачкой**: вставил 50 строк вида `word ; перевод ; пример`, и создалась категория;
  - импорт CSV/Excel.
- Автозаполнение полей. По слову подтягиваются транскрипция, определение и пример из бесплатного словаря, их можно поправить.
- **Дашборд прогресса:**
  - сегодня: изучено новых, сделано повторений, сколько осталось на сегодня, время занятий;
  - по каждой категории: сколько слов новых / изучаемых / выученных (ещё не начаты / на шагах изучения / перешли в повторение);
  - календарь активности (heatmap): видно пропущенные дни;
  - процент правильных ответов (retention);
  - список «пиявок», то есть слов, которые не запоминаются;
  - прогноз нагрузки на ближайшие дни.
- По желанию: **ежедневный отчёт в Telegram**, например вечером в 22:00: «Сегодня: 45 новых, 120 повторений, 38 мин, осталось 5».

### Поля карточки слова (под IELTS)
- word
- транскрипция
- часть речи
- перевод
- английское определение
- пример предложения
- синонимы / коллокации
- тег темы: Education, Environment, Health…

## 4. Как сделать технически (рекомендация)

### Вариант A — веб-приложение (PWA) + облачная база ✅ рекомендую

- **Фронтенд:** React + TypeScript + Vite, оформленный как PWA.
- **Бэкенд и база:** Supabase (PostgreSQL + вход по логину + защита данных по ролям). Бесплатного тарифа хватит с запасом.
- **Хостинг:** Vercel / Netlify / GitHub Pages, бесплатно.

**Установка у брата.** Открывает ссылку в Chrome или Edge и нажимает «Установить приложение». На рабочем столе появляется иконка, приложение открывается в своём окне, как обычная программа. Никаких установщиков. Работает и на телефоне.

**Ты видишь результаты** с любого устройства: свой логин, роль «админ», дашборд.

**Обновления** брат получает автоматически.

### Вариант B — десктоп-программа (Electron/Tauri) + та же облачная база
- Нужен установщик `.exe`, обновления сложнее, на телефоне не работает.
- Плюсов перед PWA почти нет.

### Вариант C — настоящий Anki + AnkiWeb
- Возможен через общий аккаунт AnkiWeb. Но у админа не будет нормального удалённого дашборда.
- Добавлять колоды удалённо неудобно.
- Нет отчётов в Telegram.
- Поэтому своё приложение оправдано.

### Модель данных (по образцу внутренней базы Anki)

```
profiles   (id, name, role: admin|student)
decks      (id, name, parent_id, student_id, created_by, options_json)
notes      (id, deck_id, word, translation, ipa, pos, definition, example,
            synonyms, tags, added_by, created_at)
cards      (id, note_id, template: recog|recall, type: new|learn|review|relearn,
            queue, due, interval, ease, reps, lapses, step_left,
            fsrs_stability, fsrs_difficulty)
revlog     (id, card_id, reviewed_at, rating 1-4, interval, last_interval,
            ease, time_ms, type)
```

Алгоритм планирования — отдельный модуль с юнит-тестами. Тесты сверяют интервалы с тем, что выдаёт настоящий Anki на тех же настройках.

### 6.1. Своё предложение со словом
- После «Показать ответ» под карточкой поле: *«Составь предложение со словом …»*. Необязательное, на расписание не влияет.
- Предложения сохраняются в таблицу `sentences (id, note_id, student_id, text, created_at)`.
- Админ видит их в дашборде и в Telegram-отчёте, может проверить.
- Позже: автопроверка грамматики предложения (этап 4).

### 6.2. Темп и нагрузка (важно)
Правило Anki: **ежедневные повторения ≈ 5–10 × количество новых карточек в день.**
Слово в обе стороны = 2 карточки.

| Новых слов/день | Новых карточек | Повторений/день (через 1–2 мес.) | Время/день |
|---|---|---|---|
| 50 | 100 | ~500–1000 | 1.5–2.5 ч ❌ выгорание |
| **25** | **50** | **~250–500** | **~45–70 мин ✅** |
| 15 | 30 | ~150–300 | ~30–40 мин |

Рекомендация:
- Категории по 50 слов оставить, это удобно тебе для добавления.
- Лимит новых в настройках колоды поставить **50 карточек = 25 слов**, то есть одна категория проходится за 2 дня.
- Обратная карточка (RU/AZ→EN) показывается **на следующий день** после прямой (bury siblings).

Объём для 6.0:
- Ориентир: около 4000 слов (уровень B2), из них базовые ~2500–3000 брат, скорее всего, уже знает.
- Учить нужно прицельно: **Academic Word List (570 семейств слов)** + тематическая лексика IELTS (~1500–2000 слов).
- При 25 словах в день это ~3 месяца.

### 6.3. Telegram
- Создаётся бот через @BotFather. Токен хранится в секретах Supabase, не в коде.
- Ежедневно в 22:00 (Баку) Edge Function + `pg_cron` шлёт админу отчёт:
  - новые слова, повторения, время, % правильных;
  - сколько осталось на сегодня;
  - пропущенные дни;
  - предложения, которые написал брат.
- **Напоминание:** если новых слов осталось меньше чем на 2 дня, бот пишет «Добавь новую категорию».

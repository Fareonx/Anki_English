# IELTS Words

Приложение для подготовки к IELTS по методу интервального повторения. Внутри оно устроено как Anki:
- колоды (категории) → слова → по 2 карточки на слово: EN→RU/AZ и RU/AZ→EN;
- алгоритм SM-2 со стандартными настройками Anki;
- лимит считает новые **слова** и общий на ученика (открытие дней по отдельности не даёт лишних слов): сегодня ученик пишет слово по-английски (RU/AZ→EN), на следующий день видит вторую сторону (EN→RU/AZ). Вторая сторона в лимит не входит, поэтому каждый день приходит ровно N новых слов;
- журнал ответов, из которого строится статистика.

План и принятые решения описаны в [PLAN.md](PLAN.md).

## Как устроено

| Часть | Технология |
|---|---|
| Приложение | React + TypeScript + Vite, устанавливается как PWA на компьютер и телефон |
| База и вход | Supabase (PostgreSQL + Auth). Доступ к данным ограничен правилами RLS |
| Алгоритм | `src/lib/scheduler/`: SM-2 как в Anki, очередь дня, лимиты, «закапывание» второй стороны слова |
| Схема базы | `supabase/migrations/` |

Роли:
- **Админ.** Первый зарегистрированный аккаунт. Добавляет слова и смотрит прогресс.
- **Ученик.** Все следующие аккаунты.

## Разработка

```bash
npm install
npm test        # тесты алгоритма
npm run dev     # локальный сервер
npm run build   # сборка в dist/
```

По умолчанию приложение подключается к проекту Supabase `ielts-anki`. Другой проект можно задать переменными из `.env.example`.

## Публикация

GitHub Actions (`.github/workflows/deploy.yml`) прогоняет тесты, собирает приложение и публикует его на GitHub Pages при каждом пуше в `master`. Включается один раз: Settings → Pages → Source: **GitHub Actions**.

## Ежедневный отчёт на почту

Каждый день в 08:00 (Баку) админ получает одно письмо по всем ученикам за вчерашний учебный день (он кончается в 04:00). По каждому ученику: новые слова, повторения, время, % верных ответов, что не доделано, серия дней, забытые слова, предложения. Если новых слов осталось меньше чем на 2 дня, в письме есть напоминание добавить категорию.

- Edge Function: `supabase/functions/daily-report/index.ts`. Расписание (`pg_cron`) и доступ к секретам: `supabase/migrations/*_daily_report_*.sql`.
- Отчёт за любой день: параметр `?day=YYYY-MM-DD`.
- Секреты лежат в Supabase Vault и не хранятся в репозитории: `resend_api_key`, `report_cron_secret`, `report_recipient`.
- Письма уходят через Resend с адреса `onboarding@resend.dev`; без своего домена Resend доставляет только на адрес владельца аккаунта.
- Проверка без отправки: запрос на функцию с параметром `?dry=1` и заголовком `x-cron-secret`.

## Добавление слов

Раздел «Добавить», режим «Быстро»: ученик пишет английские слова — одно или сразу много (с новой строки, через запятую или пробел; известные фразы вроде «thank you» остаются целыми) — и выбирает категорию. Перевод на русский и азербайджанский подставляется сразу (бесплатный Google Translate, запасной вариант — MyMemory), транскрипция и пример догружаются из dictionaryapi.dev. Если слова нет, приложение предлагает близкие варианты (Google и Datamuse). Перед добавлением всё можно поправить.

Кнопка «В последний день» кладёт новые слова в последний «День NN» курса; когда в нём набирается дневной лимит ученика, создаётся следующий день.

При вводе слова на карточке RU/AZ → EN другое верное слово (hi вместо hello, mom вместо mother) засчитывается и показывается синим вместе с основным вариантом. Проверка: поле «Синонимы» карточки, затем обратный перевод через Google.

## Наборы слов

| Папка | Для кого | Состав |
|---|---|---|
| `content/b1-core/` | Nicat (A2→B1, IELTS 6.0) | 500 слов по темам. В приложении: «День 01» — 50 слов, дальше «День 02» … «День 16» по 30 слов |
| `content/a1-start/` | Все новые ученики (с нуля) | 14 дней по 20 слов (280), темы от приветствий до школы и работы |
| `content/a2-next/` | Новички после A1 | «2. Дальше A2»: 350 слов, без повторов с A1 |
| `content/a2-confident/` | Новички, автопополнение | «3. Уверенный A2»: 14 тем |
| `content/towards-b1/` | Новички, автопополнение | «4. Путь к B1»: 14 тем |
| `content/b1-level/` | Новички, автопополнение | «5. Уровень B1»: 14 тем |

Формат строки: `word;русский;azərbaycanca;example;ipa;part of speech`.

Каждый новый ученик при регистрации сразу получает свою копию курса «1. Начало A1» и лимит 20 новых слов в день. Слова лежат в таблице `starter_words`, копию делает функция `seed_starter_course` (миграция `20261009000002_starter_course.sql`). Если поменять CSV в `content/a1-start/`, таблицу `starter_words` нужно обновить так же.

## Автопополнение слов для новичков

Все курсы для новичков (`content/a1-start` → … → `content/b1-level`) собраны в один банк `word_bank`, от лёгких слов к сложным, без повторов (1679 слов). Каждое утро в 04:05 по Баку (`pg_cron` → `top_up_all()`) база проверяет учеников с курсом «1. Начало A1»: если свежих слов осталось меньше чем на 2 дня, им добавляются следующие 14 дней слов, которых у них ещё нет, — новые «День NN · тема» в колоде нужного курса. Каждое пополнение записывается в `word_topups` и попадает в утренний отчёт; когда банк для ученика подходит к концу, в отчёте появляется предупреждение.

Как пополнить банк: добавить CSV в новую папку `content/<курс>/day-NN.csv`, вписать папку в `COURSES` в `scripts/build_word_bank.py`, затем

```bash
python3 scripts/build_word_bank.py > supabase/migrations/<время>_word_bank_data.sql
python3 scripts/build_word_bank.py --tsv > content/word_bank.tsv
```

Скрипт пропускает слова, которые уже есть в банке выше по списку.

Кнопка «➕ Ещё 5 новых слов» даёт ученику не больше +10 слов в день сверх лимита; у админа ограничения нет.

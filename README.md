# IELTS Words

Приложение для подготовки к IELTS по методу интервального повторения. Внутри оно устроено как Anki:
- колоды (категории) → слова → по 2 карточки на слово: EN→RU/AZ и RU/AZ→EN;
- алгоритм SM-2 со стандартными настройками Anki;
- лимит считает новые **слова**: сегодня ученик пишет слово по-английски (RU/AZ→EN), на следующий день видит вторую сторону (EN→RU/AZ). Вторая сторона в лимит не входит, поэтому каждый день приходит ровно N новых слов;
- журнал ответов, из которого строится статистика.

План и принятые решения описаны в [PLAN.md](PLAN.md).

## Как устроено

| Часть | Технология |
|---|---|
| Приложение | React + TypeScript + Vite, устанавливается как PWA на компьютер и телефон |
| База и вход | Supabase (PostgreSQL + Auth). Доступ к данным ограничен правилами RLS |
| Алгоритм | `src/lib/scheduler/`: SM-2 как в Anki, очередь дня, лимиты, «закапывание» второй стороны слова |
| Схема базы | `supabase/migrations/` |

Роли:
- **Админ.** Первый зарегистрированный аккаунт. Добавляет слова и смотрит прогресс.
- **Ученик.** Все следующие аккаунты.

## Разработка

```bash
npm install
npm test        # тесты алгоритма
npm run dev     # локальный сервер
npm run build   # сборка в dist/
```

По умолчанию приложение подключается к проекту Supabase `ielts-anki`. Другой проект можно задать переменными из `.env.example`.

## Публикация

GitHub Actions (`.github/workflows/deploy.yml`) прогоняет тесты, собирает приложение и публикует его на GitHub Pages при каждом пуше в `master`. Включается один раз: Settings → Pages → Source: **GitHub Actions**.

## Ежедневный отчёт на почту

Каждый день в 08:00 (Баку) админ получает одно письмо по всем ученикам за вчерашний учебный день (он кончается в 04:00). По каждому ученику: новые слова, повторения, время, % верных ответов, что не доделано, серия дней, забытые слова, предложения. Если новых слов осталось меньше чем на 2 дня, в письме есть напоминание добавить категорию.

- Edge Function: `supabase/functions/daily-report/index.ts`. Расписание (`pg_cron`) и доступ к секретам: `supabase/migrations/*_daily_report_*.sql`.
- Отчёт за любой день: параметр `?day=YYYY-MM-DD`.
- Секреты лежат в Supabase Vault и не хранятся в репозитории: `resend_api_key`, `report_cron_secret`, `report_recipient`.
- Письма уходят через Resend с адреса `onboarding@resend.dev`; без своего домена Resend доставляет только на адрес владельца аккаунта.
- Проверка без отправки: запрос на функцию с параметром `?dry=1` и заголовком `x-cron-secret`.

## Добавление слов

Раздел «Добавить», режим «Быстро»: ученик пишет английское слово (или несколько через запятую) и выбирает категорию. Перевод на русский и азербайджанский подставляется автоматически (бесплатный Google Translate, запасной вариант — MyMemory), транскрипция и пример — из dictionaryapi.dev. Перед добавлением всё можно поправить.
